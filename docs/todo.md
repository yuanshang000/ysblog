### 7. 编辑器增强（需求 5.2 部分项）

未实现：

- [ ] 侧栏可拖拽调整宽度
- [ ] 自定义 Markdown 快捷片段（Snippets）
- [ ] 编辑器内图片尺寸调整
- [ ] 多光标编辑（依赖 CodeMirror 6 等重型编辑器）

> **当前实现取舍**：使用原生 `<textarea>` 而非 CodeMirror/Monaco。
> 理由：零依赖、启动快、中文输入法（IME）兼容性天然正确。
> 代价是缺少语法高亮与代码折叠 —— 若对编辑器体验要求极高，建议后续替换为 CodeMirror 6。

### 8. 图片灯箱的图注编辑

图注通过 Markdown 图片标题语法 `![alt](url "caption")` 设置，前台自动渲染为 `<figcaption>`。
但**媒体库中的 `caption` 字段与正文图注未打通** —— 在媒体库设置图注不会自动更新已插入正文的 Markdown。

### 9. 访问统计的独立访客口径

当前 `visitor_hash = ip_hash`（同一盐值），因此：

- 独立访客数 ≈ 独立 IP 数，**不是**按「访客 + 会话」精确去重
- NAT 后的同一出口 IP 会被算作 1 个访客
- 已在后台如实标注为「估算」

若需更准确的口径，需要引入 session cookie 或更复杂的指纹方案（隐私成本更高）。

## 已知体验问题

| 问题 | 说明 |
| --- | --- |
| 中文 slug | 标题为中文时 URL 保留中文（`/posts/第一篇测试文章`）。搜索引擎支持，但 URL 可读性一般，建议发布前手动改成英文 slug |
| Element Plus 体积 | 后台 JS 约 296KB（gzip），首次加载偏重。已做路由级代码分割，后续可考虑按需引入组件 |
| 单文件代码高亮 | 内置轻量高亮器支持 JS/TS/Shell/SQL/CSS，其他语言无高亮。如需完整高亮可接入 highlight.js |
| 数学公式 | 仅做等宽字体展示，**未接入 KaTeX 渲染**。行内公式可用，复杂公式效果有限 |
